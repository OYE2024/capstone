# Пайплайн класифікації тегів

Проєкт навчає та оцінює моделі для пошуку записів із підтвердженими тегами. Відсутність тегу не означає, що запис перевірений і є негативним.

## Етапи

- **Етап 1:** LightGBM або CatBoost; налаштування балансування, відбору ознак і порога. Після навчання зберігаються графіки Logloss та Average Precision.
- **Етап 2:** CatBoost із методом nnPU або SAR-PU; навчання потребує підготовлених результатів аудиту.
- Калібрування score виконується окремим кроком.

## Запуск

1. Встановіть залежності: `pip install -r requirements.txt`.
2. Розмістіть дані в `datasets/data.csv`. Приклад колонок без даних — `datasets/example_data.csv`.
3. Налаштуйте `CONFIG` у `pipeline.py`.
4. Запустіть повний конвеєр: `python pipeline.py --stage all`.

Детальні інструкції наведені у [RUNBOOK.md](RUNBOOK.md). Результати кожного запуску зберігаються в окремій папці `outputs/`.
